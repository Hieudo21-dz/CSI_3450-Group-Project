Final Project — 250 Points 
The final project allows you to apply the database concepts covered throughout the semester to a 
practical computing problem. 
You may refer to pages 156–166 of the eBook for project ideas, but your project must be based on an 
original case study. You may either extend a previous homework assignment or develop a new project 
from scratch. In either case, all requirements below must be satisfied. 
 
Project Deliverables and Submission — 5 Points 
Submit one ZIP file containing: 
1. Project Implementation 
2. Project Report — .docx or .pdf 
3. Presentation Slides — .ppt, .pptx, or .pdf 
Name the ZIP file: 
Final_YourGroupName.zip 
Late submissions will not be accepted. 
 
1. Project Implementation — 115 Points 
Implement a functional relational database using Microsoft SQL Server and connect it to an external 
computing platform, such as a web application or API. 
Database Requirements 
Your project must include: 
• Appropriate tables, attributes, primary keys, foreign keys, relationships, and constraints. 
• Proper data types and normalization. 
• Sufficient sample data. 
• SQL queries for creating, populating, and managing the database. 
• Meaningful queries for retrieving and reporting data. 
Submit a .txt file containing all SQL queries used in your project. 
Connectivity and Integration 
Connect your SQL Server database to a web application or API. 
Your implementation must demonstrate: 
• A working connection between SQL Server and the external platform. 
• The tools, programming language, framework, driver, or connector used. 
• Data retrieval from the database through the application. 
• Data insertion and/or updating through the application.

3. Project Presentation — 60 Points 
All groups must present their projects according to the scheduled timeline. 
The presentation must include: 
• Project overview and problem statement 
• Database design and ER model 
• Relational database model 
• SQL Server implementation 
• Database queries  
• Application/database connectivity 
• Live demonstration or recorded walkthrough 
• Project outcomes and impact on Individual and groups 
• Distribution of Works and challenges 
The presentation should be clear, organized, concise, and engaging.  
All team members must attend the presentation in person and participate in the presentation. 
 
Project Policies 
• The project must be completed in a team of three students. 
• Every member must make a meaningful contribution. 
• All requirements must be completed. 
• All project code and materials must be original and self-written. 
• Copied projects or code will not be accepted. 
 
Project Competition 
A winning group will be selected based on votes from the students. Each member of the winning group 
will receive 10 bonus points, increasing the project score from 250 to 260 points. 
Voting Rules: 
• You cannot vote for your own group.  
• Submit your vote online before the final decision.  
Voting Criteria: 
• Quality and technical implementation  
• Presentation and teamwork  
• Creativity and project idea  
• Time management  
• Overall impact
